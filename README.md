# 뜀로그 (dduim.log)

러너들이 나만의 동네 러닝 코스를 직접 그리고 공유하는 모바일 최적화 웹 플랫폼입니다.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Vercel 배포 예정
- Supabase/PostGIS, Kakao Maps 연동 예정

## Getting Started

개발 서버 실행:

```bash
pnpm dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.
